# Support

GEO Starter is currently a Community alpha scaffold.

## Community Alpha Support

- Use the Drupal.org issue queue for bug reports, install failures, documentation gaps, and release-readiness findings.
- Security issues should follow `SECURITY.md`, not public issues.
- Marketplace-level support commitments are not active for this alpha.

## Marketplace Support Requirement

Before Marketplace submission, replace this section with a named support owner and support process, including:

- responsible organization or individual;
- expected first-response window;
- supported Drupal CMS and PHP versions;
- security response path;
- paid or free support model;
- maintenance/release cadence.

Do not submit this template to the Official Marketplace until those commitments are real.
