## ADD — optional MCP add-on docs (Alex's "+ optional MCP")
A short `docs/OPTIONAL_MCP.md` (linked from README) documenting the manual opt-in,
clearly marked EXPERIMENTAL/unsupported: to expose an agent MCP endpoint, a site
operator may `composer require drupal/mcp_server:1.x-dev` + `drupal/simple_oauth`
under a relaxed `minimum-stability`, enable them, and configure OAuth scopes. Note the
typed-GEO tools + moderation-gated `geo_agent` role (the `geo_starter_mcp` companion)
will ship as a separate package once `drupal/mcp_server` has a stable release. NO
recipe-required dep; the stable `composer require drupal/geo_starter` floor stays
clean.

1. `composer require drupal/geo_starter` resolves at the DEFAULT stable floor with
   NO mcp_server/simple_oauth (the headline 1.0.0 property must survive). Prove via

2. Fresh `drush site:install` green: JSON-LD probe 23/23, content-graph-lint OK,

   build; `scripts/quickstart.sh` parity.
4. `php tools/generate-content-model-schema.php --check` passes against the real
   `config/` (no schema drift); `docs/api/openapi.yaml` lints.
5. No residual MCP references in shipped docs except the clearly-marked optional
   add-on; `composer validate --strict` passes.
6. README/CHANGELOG/LIMITATIONS reconciled (copy-critic pass, as for 1.0.0).
